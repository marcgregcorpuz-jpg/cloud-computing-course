# Cloud Computing Reflection

Cloud computing has become an essential part of my daily life because many of the applications I use depend on cloud technology. Three cloud services that I regularly use are Google Drive, Facebook Messenger, and Canva. These applications allow me to study, communicate, and complete school projects efficiently from any device with an internet connection.

Google Drive is an example of Software as a Service (SaaS) because I use it through a web browser or mobile application without managing the underlying hardware or software. It is deployed using the Public Cloud since it is available to millions of users over the internet. Facebook Messenger is also classified as SaaS because it provides messaging services directly to users through the cloud. Like Google Drive, it operates on the Public Cloud because anyone with an account can access the service online. Canva is another SaaS application because it allows users to create presentations, posters, and other designs without installing professional design software. It is also hosted in the Public Cloud, making it accessible from anywhere.

Version control is an important part of cloud computing because it keeps track of every change made to files, configurations, and source code. If mistakes happen, previous versions can be restored, reducing the risk of losing important work. Git provides a reliable version control system, while GitHub allows developers to collaborate by sharing repositories, reviewing changes, and managing projects together. Team members can create branches, merge updates, and resolve conflicts without overwriting each other's work.

Through this activity, I realized that cloud computing is more than simply using online applications. It involves organized storage, collaboration, and efficient resource management. Learning Git and GitHub will help me become a better IT student because these tools are widely used in software development and cloud infrastructure management. I believe these skills will also prepare me for future academic projects and professional work in the technology industry.
